# Nota de versión para usuarios

## Qué salió en esta rama

En esta versión la app queda más preparada para uso estable y para la distribución en Play Store. La base del producto se consolida con mejoras en la experiencia de llamadas, el acceso rápido, el inicio de sesión del usuario y la adaptación al idioma.

### Cambios visibles para el usuario

- La app ya está en una versión más estable y preparada para publicación y uso en producción.
- Se mejoró la experiencia de llamadas de prueba y la pantalla de llamada con temas, llamadas perdidas y cierre automático de llamadas.
- Ahora puedes programar llamadas que llegan incluso si la app está cerrada o bloqueada.
- La interfaz está disponible en español e inglés.
- Se mejoró el arranque y la primera experiencia con una intro más clara y una navegación de botones y selección más consistente.
- Se reforzó el seguimiento de uso con Firebase Analytics y el control de actualizaciones forzadas para asegurar que las instalaciones con versiones antiguas reciban una ruta correcta.

## Nota corta para Play Store

Mejoras de estabilidad y experiencia de llamadas. Ahora la app ofrece una base más consistente para llamadas rápidas, llamadas programadas, soporte de idioma y una primera ejecución más fluida. También se corrigen problemas en botones, intro y modales para que el flujo sea más claro.
